# example 真实模型验证（2026-09-24）

## 验证范围

使用 `example` 根目录中的 3 个 STEP/STP 文件，实际运行：

- OCCT 几何分析与 STL 转换；
- 制造特征归一化和回转轮廓识别；
- Citizen Cincom L32 确定性工艺规划；
- Qwen + LangGraph 影子规划、风险审查和晋级门禁；
- 正式方案批准门禁；
- L32 专用 DRAFT Toolpath IR 入口和通用 CAM 阻断门禁。

详细机读报告保存在 `.seksun-cnc/example-validation-report.json`，API 任务记录保存在 `.seksun-cnc/example-api-validation/`。

3 个模型的几何分析均完成，没有 STEP 解析失败。所有正式方案都是 `automation_status=review`、`coverage.production_ready=false`。

## 发现并修复的系统问题

1. 基准工具原先只扫描 `example/子目录/*.step`，会遗漏根目录模型，导致错误的 `case_count=0`。现已支持根目录 STEP/STP 发现并增加回归测试。
2. 正式方案覆盖率为 0，智能体影子评测也已拒绝晋级，但原 `/approve` 接口仍可返回 200。现已增加强制门禁：
   - `coverage.production_ready` 必须为 true；
   - 不允许存在未覆盖或待复核制造目标；
   - `agent-evaluation.json` 的晋级门禁失败会阻止批准。

## 安全边界验证

- 3 个任务进入通用 CAM 均返回 409：L32 未认证后处理器不允许输出通用生产 NC。
- 3 个任务调用 L32 DRAFT 刀路均返回 422：精确回转轮廓尚处于 `review`，必须由工程师先确认。
- 本次验证没有代替工程师自动把轮廓标记为 `accepted`，也没有伪造生产仿真结果。

## 下一个技术缺口

Qwen 已能正确发现漏掉的径向孔、大内孔和非回转区，但当前候选方案编译器不会将只有文本建议、缺少完整刀具/参数的 `add` 动作写入正式工序，因此候选方案的工序数和覆盖率没有改善。下一阶段应实现“AI 建议 → 结构化工序草案 → 能力库/刀具库编译 → 确定性覆盖复验”，而不是直接放开影子方案。
