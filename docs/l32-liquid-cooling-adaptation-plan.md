# L32 液冷典型结构专项适配开发方案

> 文档版本：1.0  
> 日期：2026-09-16  
> 状态：实施中（M0、M1 完成，M2 螺纹及精确内轮廓审核闭环已落地）  
> 上位方案：[`l32-cam-adaptation-plan.md`](./l32-cam-adaptation-plan.md)  
> 样例根目录：`example/液冷项目典型结构图纸`

## 1. 决策与目标

本专项将“液冷项目典型结构图纸”定义为 L32 第一阶段的产品范围，不以“支持所有 L32 零件”为交付口径。

目标分为三个等级：

| 等级 | 定义 | 本专项承诺 |
| --- | --- | --- |
| L1 工艺识别 | 正确识别零件族、回转轴、毛坯、制造特征和能力边界 | 必须完成 |
| L2 CAM 草案 | 生成可审查工序、Toolpath IR、余料/过欠切结果和明确阻断 | 必须完成 |
| L3 生产 NC | 输出绑定实际设备配置、可回读并经实机认证的 MELDAS 程序 | 条件性交付，现场资料齐备后启动 |

第一阶段的完成定义是：范围内样例全部得到确定、可重复、可解释的结果；不能识别或不能加工时必须安全阻断。没有真实机床配置、编程手册和黄金 NC 时，系统只能输出 `DRAFT`，不得声称可直接上机。

### 1.1 实施进度

截至 2026-09-16：

- M0 已完成：24 个 case 的版本化 manifest、显式配对、输入哈希、预期基线、API/CLI/Docker 同源发现和报告版本信息已经接入。
- M0 部署验收通过：24 个模型和 PDF 均可访问，22 个配对已确认，2 个配对保持 `needs_review`。
- M1 安全门禁已完成：增加横截面证据、多实体阻断和非回转拒绝；`unsupported` 不再生成占位车削工序。
- 当前 24 个 case 的“零件族 + 设备能力”基线断言以精确截面重新校准；这不代表 `required_features` 和 CAM 刀路已经完成。
- M1 已完成：OCCT 精确 Z-R 外/内截面、来源面追溯，以及旧分析结果的可视边投影回退。
- 24 个 case 中 18 个已使用 `exact_section`；4 个安全回退到边投影，1 个非回转件被拒绝，1 个多实体件要求先选择实体。
- 精确内截面仍为 `review`，不会自动生成内孔工序；带实体螺纹的轮廓简化将在 M2 特征拆分时继续优化。
- M2 已启动：`LC-L32-203` 已建立圆柱段、锥面/圆弧离散段、径向台阶、外槽候选、内孔段和切断边界的数据模型；当前均为审核候选，尚未自动增加工序。
- `LC-L32-204` 已建立 UNF/UNC/UNEF/G(BSPP) 结构化螺纹模型，支持 OCR 分数、大径、TPI、毫米螺距、牙型角、配合等级、旋向与内外螺纹解析。
- 周期性实体牙形会折叠为 `thread_form_candidate`，保留观测重复距离和两个安全螺距候选；只有图纸螺纹要求完成唯一几何绑定后，才能选择正式螺距并进入工序编译。
- 测量服务已能从真实 BUQD0292 PDF 文本层提取并去重 `3/4-16 UNF`；重复文本对象的坐标会作为审计证据保留。文件名只作为低置信度审核线索，不允许自动绑定。
- 未验证的图纸螺纹与唯一周期牙形只形成 `ambiguous` 建议；只有验证状态和唯一性同时满足时才升级为 `matched`。
- 已增加制造工程师螺纹绑定确认接口；确认时同时校验螺距和大径，并记录确认时间、要求 ID 与 STEP 周期牙形 ID。
- 确认后规划器会加入 `turn_threading` 草案，但该工序固定为默认禁用；螺纹起止、退刀槽、刀片和控制器循环未确认前不得进入生产 NC。
- L32 工作台已增加螺纹证据绑定面板，显示图纸/STEP 螺距、大径及各自校验结果，并可执行工程师确认；已确认状态会明确显示对应草案仍为禁用。
- 已增加螺纹 DRAFT 工序二次审核：必须确认起止 Z、径向牙深、切削次数、退刀策略/宽度、刀片实物编号、控制器循环标识和审核人，校验通过后才启用控制器无关仿真。
- 自动绑定螺纹工序禁止通过通用工序编辑接口绕过审核；DRAFT 请求必须与服务器保存的已审核工序完全一致。
- 螺纹 IR 已从单条抽象循环扩展为逐刀语义序列，采用递减切深分配并记录刀次、累计牙深和每刀目标直径；仍不映射任何现场 G/M 代码。
- 螺纹仿真已支持牙底旋转包络材料去除，并增加刀次数量、大小径/牙深一致性、末刀牙底、有效长度、退刀空间、仿真覆盖范围等专项检查。
- BUQD0292 真实 PDF+STEP 作业已通过闭环验证：`3/4-16 UNF` 解析为 1.5875 mm 螺距，绑定到周期牙形后生成 1 条禁用螺纹草案，启用的螺纹工序数为 0。
- 回转轮廓人工审核结果已写回几何分析并在重新分析后保留，避免内孔工序因刷新而丢失审核依据。
- 只有 `exact_section + accepted` 的内轮廓才会生成 OP25 内孔粗镗和 OP28 内孔精镗草案；两道工序均默认禁用，边投影轮廓或未确认轮廓不会进入自动内孔规划。
- 已增加内孔 DRAFT 专用审核接口与工作台表单：必须提供初始孔径、已确认镗杆伸出、装配间隙、镗杆库存实物编号和审核人。
- 内孔启用前会检查镗杆入口、最小径向空间、轴向可达深度、刀具方向、毛坯包络和隐藏倒扣；失败时返回明确阻断项并保留禁用状态。
- 自动内孔工序禁止通过通用编辑接口修改刀具、参数或启用状态；DRAFT 请求必须与服务器保存的已审核工序完全一致。
- 已为确认后的精确内轮廓增加 OP22 轴向预孔草案，推荐钻径同时受粗镗杆入口下限和最小成品孔精加工余量上限约束，且默认禁用。
- OP22 启用前必须确认钻头目录型号与现场实物编号、伸出、有效刃长、钻尖角、啄钻深度、孔底条件和允许钻尖越程；盲孔越程不足时硬阻断。
- 轴向钻削仿真已模拟完整钻径段与圆锥钻尖段；镗孔审核必须引用同一内轮廓下已审核 OP22 的实际直径和有效深度，不能再提交任意“初始孔”数值。
- 内轮廓计划现记录圆柱孔段数量、总深度和最大长径比；当实际预孔超过 `5×D` 时，普通啄钻策略会被阻断。
- 深孔 OP22 必须选择分级退刀排屑策略、限制单次啄钻不超过 `0.5×D`，并确认现场刀具内冷；这些状态会进入 Toolpath IR 和审核制品，换刀或换冷却配置后需重新审核。
- 已将精确内轮廓中的 `inner_bore` 恒径段编译为最多三道独立阶梯预孔草案，按“最深小径→较浅大径”排列，并为每级保存目标孔径、加工深度、余量上限和独立 L/D。
- 后续大径孔级必须在所有更深孔级完成工程审核后才能启用；镗孔审核要求全部已规划孔级通过，避免只确认引导孔却遗漏浅层扩孔。
- L32 工作台已支持在同一 `axial_drilling` 类型下选择具体 OP22-Sn 工序，逐级审核实际钻头、孔深及深孔条件。
- 已增加内孔连续余料链：按 OP22-S1/S2/S3 → OP25 → OP28 顺序将每一阶段的 Z-R 材料状态传递给下一阶段，并输出合并 Toolpath IR、阶段去除体积、最终余料和程序哈希。
- 连续链会检查工序审核完整性、阶梯孔顺序、材料体积单调减少、任一中间阶段过切及 OP28 最终轮廓；尖锐内肩无法容纳当前刀尖圆弧时会明确阻断，而不是用独立仿真掩盖问题。
- 规划器会统计精确内轮廓中的尖锐径向台阶；存在尖锐内肩时，OP28 审核强制选择 `small_nose_tool` 策略、现场实物编号及刀尖半径不大于 `R0.05 mm` 的内孔精车刀。
- 刀具目录已加入 `TURN-ID-MICRO-F` 作为可验证的微小刀尖 DRAFT 模型。普通 `TURN-ID-F (R0.2)` 会被尖肩门禁拒绝；使用经审核的微小刀尖刀后，合成阶梯孔的 OP22-Sn → OP25 → OP28 连续余料链通过。
- 尖锐内肩当前只执行已由仿真覆盖的小刀尖精镗策略；“图纸允许圆角”仍仅作为后续建议，不能绕过精确轮廓验证。
- 已将已接受精确外轮廓中的 `external_groove_candidate` 编译为默认禁用的 OP33-Gn 外槽草案；边投影轮廓、未接受轮廓及内槽候选不会进入该流程。
- OP33-Gn 必须确认槽宽、槽底直径、径向分层切入量、槽形、切槽刀目录型号、现场实物编号和审核人；尺寸与精确轮廓不符、刀宽大于槽宽或单次切入超过槽深时硬阻断。
- 宽槽 Toolpath IR 已按实际切槽刀宽拆分多个轴向刀位，并在每个刀位按确认切入量执行径向分层，不再用单条指令虚拟覆盖整个槽宽。
- 已识别精确内轮廓中“半径高于两侧基孔”的矩形 `internal_groove_candidate`；OP25/OP28 粗精镗会抑制该局部凹槽，仅加工连续基孔，避免纵向镗刀伪装成内槽刀。
- 内槽编译为默认禁用的 OP32-IGn，并强制使用 `internal_grooving` 刀具。审核除槽宽、槽底和实物编号外，还要求基孔精镗已通过、刀杆伸出和装配间隙满足槽位深度。
- 内槽采用孔内安全退刀直径，从基孔向外径向分层切入，并加入 OP22-Sn → OP25 → OP28 → OP32-IGn 连续余料链；只有最后一道内槽后完整内轮廓验证通过才允许 DRAFT 链通过。
- 当前内槽支持范围限定为精确截面中的锐边矩形槽；圆弧槽、斜槽、端面槽和异形密封槽仍保持审核/阻断，不做几何猜测。
- 修正了内孔粗镗在剩余余量小于单刀切深时遗漏首刀，以及精镗在同 Z 台阶处错误连接大小径形成对角刀路的问题。
- 当前自动化回归为 API `218 passed`，Web TypeScript/Vite 生产构建通过；这只代表 DRAFT 软件门禁，不代表现场刀具或 NC 已认证。
- 已识别外槽会从普通外圆纵向粗精车基准轮廓中桥接剥离，防止普通车刀误入局部槽；前端倒角允许先增径至主体外径，进入较小直径后再次反向增径仍按隐藏倒扣硬阻断。
- 单工序验证已区分加工语义：轮廓车削和已审核槽加工保留 Z-R 轮廓验证，端面和切断不再错误声明整件最终轮廓验证结果。
- OCCT 精确截面选择已与通用加工特征筛选解耦：来源圆柱面即使因局部长度被排除，只要截面与认可主轴共线且轴向覆盖充分，仍可作为完整回转轮廓证据。BUQD0094 已恢复精确内外截面，并已将外轮廓拆为前端成形、主纵车和背面候选三个区域。前端四工序和背面 OP55-BACK/OP58-BACK 连续余料链均通过；旧版 OP60 已从区域方案移除。OP40 现将刀中心、成品背面 Z0 与保留材料边界分离，使刀缝落入牺牲余料；区域工序已进入正式九工序双通道整件 DRAFT，并在模拟 U150B 配置和实际认可轮廓上通过跨坐标最终轮廓校核。实际验收设备未声明背面刀具模块，区域仍保持 uncovered，且无生产 NC。

## 2. 样例盘点基线

### 2.1 自动分析结果

2026-09-15 对目录中的 24 个 STEP/STP 模型进行了只读分析：

- 24/24 几何分析完成。
- 19 个模型按当前精确几何和余量策略可进入标准 Ø32 范围。
- 1 个模型需要 Ø38 棒料选件。

### 2.2 配对问题

1. `BUQD0035_F UQD04 外壳C.pdf` 与 `BUQD00XX-ACC_B UQD04 外殼C.stp` 疑似同件，需人工确认。

## 4. 产品范围

### 4.1 纳入范围

- 单实体棒料回转件。
- 端面、外圆粗精车、阶梯、锥面和圆弧。
- 轴向钻孔、镗孔、阶梯孔和通孔。
- 外槽、内槽、密封槽、退刀槽和切断。
- 公制、UNF 和 G 管螺纹的结构化输入与语义刀路。
- C 轴定位后的径向钻孔和圆周阵列孔。
- C/Y 定位后的铣平和简单槽加工。
- 主轴正面工序，以及在人工确认分界面后的背轴接料/背面草案。
- 图纸材料、棒料、螺纹、粗糙度和关键技术要求的提取与人工确认。
- L32 标准 Ø32、Ø38 选件和超规格三态能力判断。

### 4.2 暂不纳入

- B 轴连续联动和自由曲面五轴加工。
- 自动推断现场 M 代码、同步代码和 PLC 宏。
- 在没有目标实体确认时自动拆解多实体装配。
- 将 CAMotics 结果作为车削或多通道放行证据。
- 未经空运行、试切和首件检验的生产 NC 放行。

## 5. 核心设计

### 5.1 版本化样例清单

新增仓库内版本化 manifest，不移动也不改写用户原始样例。建议位置：

```text
apps/api/benchmarks/manifests/l32-liquid-cooling.v1.json
```

每个 case 至少包含：

```json
{
  "id": "BUQD0292",
  "model": "液冷项目典型结构图纸/BUQD0292_A ... .step",
  "drawing": "液冷项目典型结构图纸/BUQD0292_A3 ... .pdf",
  "pairing_status": "confirmed",
  "expected": {
    "part_family": "rotational_mill_turn",
    "material": "SUS316L",
    "bar_diameter_mm": 25,
    "machine_capability": "standard",
    "required_features": ["outer_profile", "axial_bore", "seal_groove", "external_thread"],
    "thread_designation": "3/4-16 UNF"
  }
}
```

`benchmarks.py` 需要支持“子目录自动发现”和“manifest 显式配对”两种模式。生产逻辑不得通过文件名特判某个料号。

### 5.2 回转件分类器

将当前“找到任意圆柱面即建立回转候选”改为多证据判定：

1. 从圆柱、圆锥和圆面集合聚类候选轴。
2. 计算同轴圆柱/圆锥面积占比。
3. 沿候选轴生成多个精确截面，计算截面圆度与半径分布。
4. 计算绕轴旋转后的实体差异或截面覆盖率。
5. 检测薄板、偏置主体、L 型主体和多实体输入。
6. 将径向孔、铣平和局部槽作为允许的非轴对称减材特征，而不是直接否定主体。

输出状态：

- `accepted_candidate`：主体回转证据充分，局部复合特征可解释。
- `review`：轴或目标实体存在歧义。
- `not_rotational`：主体非轴对称。
- `unsupported`：主体可识别但超过设备能力。

硬规则：状态为 `not_rotational`、`unsupported` 或多实体未确认时，不得生成 OP10～OPxx 工序占位符。

### 5.3 精确 Z-R 轮廓

在 `services/geometry` 中增加 OCCT 精确截面输出：

- 外轮廓和内轮廓分离。
- 保留直线、圆弧、锥面和槽边界语义。
- 对微小边、重复边和螺纹建模细节做容差归并。
- 输出轮廓闭合性、连续性、自交和来源 face IDs。
- 复杂样例轮廓点经过公差化后应为可审查规模，不再直接使用数千个可视边点。

只有 `exact_section` 或人工接受的等价轮廓可以进入正式 CAM 草案。

### 5.4 图纸要求优先级

建立以下值来源优先级：

1. 人工确认的图纸要求。
2. 已与 CAD 特征唯一绑定的图纸/PMI 要求。
3. STEP 精确几何。
4. 规则默认值。

因此 BUQD0292 的毛坯必须使用图纸 Ø25，不能因为自动添加余量而改成 Ø26.5。系统应分别保存：

- `specified_stock_diameter_mm`
- `estimated_minimum_stock_diameter_mm`
- `selected_stock_diameter_mm`
- `stock_source`
- `stock_conflict`

当指定棒料小于成品几何包络时必须阻断并要求复核，不得静默覆盖图纸值。

### 5.5 特征图

为液冷件增加回转复合特征类型：

- `outer_turn_profile`
- `inner_turn_profile`
- `face`
- `external_groove` / `internal_groove` / `seal_groove`
- `external_thread` / `internal_thread`
- `axial_hole` / `radial_hole`
- `circular_hole_pattern`
- `milled_flat`
- `milled_slot`
- `cutoff_boundary`
- `backside_feature`

每个特征必须包含来源几何、置信度、审查状态、加工方向、主/背面归属及图纸要求绑定。

### 5.6 工序规划与能力路由

规划器按特征和机床快照产生工序，不生成固定六工序模板：

```text
材料/棒料确认
  → 主轴夹持与导套模式
  → 端面
  → 外圆粗/精车
  → 轴向钻/镗
  → 槽
  → 螺纹
  → C 轴径向钻孔
  → C/Y 铣平或铣槽
  → 背轴接料（如需要）
  → 切断
  → 背面加工（如需要）
  → 检验要求
```

能力路由必须检查：

- 标准 Ø32、Ø38 选件及现场配置直径。
- 主轴/动力刀具转速和夹持能力。
- B、Y2、背面动力刀具等模块是否实际安装。
- 钻孔直径、镗杆长径比、刀杆入口和隐藏倒扣。
- 径向加工是否仅需 C 定位，还是还需要 Y/B 轴。
- 每个工序的主轴、通道、刀台和资源占用。

### 5.7 CAM 与验证

- 车削继续使用确定性 Turning Provider，不依赖 FreeCAD Turning。
- 径向孔、铣平和简单槽复用现有 FreeCAD 铣削 Provider，但必须经过 L32 坐标映射层。
- 所有 Provider 输出统一 Toolpath IR。
- 车削使用 Z-R 余料、过切、欠切和可达性验证。
- 动力刀具使用三维材料去除和保守碰撞包络。
- 复合程序在通道时间线中校验资源冲突、同步屏障和死锁。
- 后处理前后执行 IR → NC → Replay 语义一致性检查。

## 7. 自动化验收矩阵

| Gate | 指标 | 通过标准 |
| --- | --- | --- |
| G0 数据完整性 | manifest、文件存在、配对状态 | 24/24 可发现；未确认配对明确标记 |
| G1 几何稳定性 | OCCT 分析成功率 | 24/24；单件超时可诊断，无静默失败 |
| G2 分类 | A/C 级样例分类 | 黄金正向和硬失败样例 100% 符合预期 |
| G3 毛坯 | 图纸值、估算值、设备能力 | 三值分离；冲突硬阻断；选件明确提示 |
| G4 特征 | 必需特征覆盖 | A 级 `required_features` 全部识别或明确 review |
| G5 工序 | 特征到工序可追溯 | 不允许无来源固定模板；禁用/阻断工序不计覆盖 |
| G6 刀路 | IR schema 与几何验证 | 100% 可序列化；无越界；过切/欠切在配置阈值内 |
| G7 复合加工 | C/Y 定位、模块和碰撞 | BUQD0302/0330 通过；缺模块负例通过 |
| G8 发布 | 生产门禁 | 无认证 Post 或配置不一致时 `nc_generated=false` |
| G9 回归 | 既有 VMC/钣金流程 | 现有自动化测试保持通过 |

每次报告必须包含：case ID、输入哈希、代码版本、分析器版本、机床快照哈希、识别结果、工序覆盖、验证结果、阻断原因和与上次基线的差异。

## 10. 风险与控制

| 风险 | 控制措施 |
| --- | --- |
| 图纸和模型编号不一致 | manifest 显式配对，未确认时禁止图纸驱动参数 |
| 图纸 OCR 丢失直径/螺纹符号 | 原文、置信度和人工确认并存；不做静默猜测 |
| 将局部径向孔误判为主轴 | 主体面积/截面证据优先，局部特征单独分类 |
| 将 L 型件误判为回转件 | 轴对称度、截面差异和包络填充硬门禁 |
| 图纸棒料与自动余量冲突 | 分开保存指定值和估算值，冲突阻断 |
| 多实体装配误加工 | 用户选择目标实体前禁止规划 |
| FreeCAD 坐标直接用于 L32 | 强制经过机床坐标映射层 |
| 没有现场代码仍输出 NC | 未认证 Post、机床快照或人工批准时 hard fail |
| 测试页面仍展示旧镜像/旧报告 | 报告和 UI 展示版本、哈希与生成时间 |

## 11. 依赖与用户侧输入

M0～M3 可以立即实施。M4/M5 需要逐步补齐：

- 确认 `BUQD0035 ↔ BUQD00XX`、`BUQD0078 ↔ UQD06` 两组配对。

- 控制器软件版本、Citizen/MELDAS 编程手册。
- 至少一份已验证的单主轴程序。

- 可用于空运行、试切和首件测量的现场窗口及负责人。

## 12. 推荐执行顺序

第一开发批次只做 M0 + M1：

1. 固化 24 个 case 的 manifest 和期望结果。
2. 让 CLI、API、Docker 和页面读取同一份版本化基线。
3. 修正回转件分类，先确保“该进的进、该拒绝的拒绝”。
4. 接入 OCCT 精确截面，替换可视边投影作为正式轮廓来源。
5. 用 BUQD0017、BUQD0292、BUQD0325、QD028 Retainer 四个最小集合验收。

M0 + M1 通过后再进入 M2。这样可以防止后续车削、螺纹和动力刀具开发建立在错误轴线或错误毛坯上。
