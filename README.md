# Seksun CNC

## v0.9 原生 FreeCAD CAM

- `cam.FCStd` 现在保存可编辑的 FreeCAD Path `Job`、`ToolController` 与原生工序对象，不再用手工拼接的通用 `Path::Feature` 代替 CAM 工序。
- 已接入原生钻孔、外轮廓、Holding Tags 桥位、型腔/槽及面铣映射；G-code 和网页刀路预览均从原生工序路径派生。
- 工作台采用 NX/UG 风格布局：顶部菜单和功能区、左侧工序树与参数面板、右侧 3D 图形区、底部工序顺序区。
- 启动后访问 `http://localhost:3001/jobs/{job_id}`，批准方案并点击“生成”即可重新生成原生 CAM 工程。

面向机加工工艺规划的可审查 AI CAPP 原型。

```text
STEP → OCCT 几何/特征分析 → 规则式工艺规划 → 人工审查 → FreeCAD Path → GRBL G-code
```

当前 v0.8 聚焦三轴、2.5D 棱柱类零件，已提供：

- STEP 上传、OCCT 精确解析和 STL 预览
- 多实体 STEP 完整预览；当前默认以最大实体作为加工主体，其他实体保留为装配参考
- 平面、孔、矩形封闭型腔和单向贯通槽候选识别
- 面邻接高低关系过滤凸台、开放台阶等伪型腔
- 按加工方向生成 Setup，按特征、刀具生成 OP 工艺草案
- 3D 模型、特征标记、工序联动审查，支持确认或排除候选
- 工艺方案全量批准后，调用 FreeCAD Path 0.20.2 生成 CAM 草案
- 生成可下载的 `cam.FCStd`、GRBL `program.nc` 和 `toolpath.json`
- 在浏览器中叠加显示快移与切削刀路
- 版本化材料、刀具和机床参数库，自动计算并限制 RPM、切削进给与下刀进给
- CAM 后静态安全预检：机床行程、参数范围、刀具直径与工序覆盖率
- 可下载的 `verification.json` 预检报告和“仿真”工作区
- 自研三轴高度场材料去除内核，按实际刀具直径扫掠刀路
- 加工后毛坯 3D 表面叠加、去除/剩余体积和自适应网格精度统计
- 仿真页动态材料去除：从完整毛坯开始，刀具在 `+Z` 切削段实时移除高度场材料；支持暂停、回退重建、进度拖动和 1×/5×/20× 播放
- 可下载的 `simulation.json`，用于复核或接入后续独立仿真服务
- 可配置安全间隙和平口钳夹持高度；保存后自动撤销旧方案批准
- 根据零件包围盒生成前/后钳口禁入区，并在 3D 仿真视图中以红框显示
- 沿实际刀路采样刀具与刀柄圆柱包络，检查夹具、毛坯碰撞和低安全平面快移
- 可下载 `collision.json` 碰撞报告，碰撞项按工序和目标去重并定位
- `±X / ±Y / ±Z` 装夹方向分别转换为局部 `+Z` 工作坐标生成 CAM；多 Setup 程序插入换装暂停
- 圆柱面使用真实轴线中心合并 STEP 拆分面，并增加圆周覆盖角判据：完整拼合圆孔可恢复，开口圆弧、槽端和外轮廓圆角不再误识别为钻孔
- 薄板异形件支持外轮廓加工：自动选择顶面外环、向材料外侧补偿刀具半径、分层切透并在最终层保留四个桥位
- 通孔钻削深度包含 118° 麻花钻钻尖长度与 0.5 mm 穿透余量，预检单独验证有效通孔深度
- 薄板自动改用牺牲垫板方案，并校核刀具切入垫板深度及下方硬限位；外轮廓毛坯单边余量提高到 4 mm
- CAM 生成后以实际刀路线段重新计算并统一显示循环时间；未绑定真实控制器时明确把 GRBL 输出标记为草案告警
- 外轮廓切透后仿真隐藏外侧废料，并将剩余材料体积与 STEP 目标体积的偏差纳入预检
- 持久化任务会话；刷新或通过 `/jobs/{job_id}` 可恢复已经运行的任务
- 一键复制内网只读分享链接；访问者可查看工艺、播放仿真和下载报告，但不能修改或批准方案
- 已有任务可点击“重新分析”应用最新识别规则，并自动清理失效的 CAM 产物

## 快速启动

需要 Docker Desktop：

```powershell
docker compose up --build
```

工作台：<http://localhost:3001>  
API 健康检查：<http://localhost:8090/health>

首次构建需下载 FreeCAD/OCCT 运行时，耗时会明显长于后续增量构建。

如需将任务分享给同一内网的其他人，在 `.env` 中配置本机可访问地址后重启服务：

```dotenv
CNC_PUBLIC_BASE_URL=http://192.168.1.100:3001
```

进入任务后点击“复制分享链接”。普通任务地址为 `/jobs/{job_id}`，只读分享地址为 `/jobs/{job_id}?view=1`。当前版本未提供身份认证，知道链接且能够访问服务的人均可查看和下载该任务的数据。

## 使用流程

1. 上传 STEP 文件，等待特征识别与工艺规划完成。
2. 在 3D 视图和特征清单中确认或排除候选特征。
3. 点击批准工艺；未全量批准时后端拒绝 CAM 生成。
4. 点击生成 CAM，查看刀路并下载 G-code 草案或 FreeCAD 工程。
5. 在“仿真”页复核红色夹具禁入区、碰撞检查、静态预检和材料去除结果。

核心接口：

- `POST /api/v1/jobs`：上传 STEP 并生成分析及工艺草案
- `POST /api/v1/jobs/{job_id}/reanalyze`：使用最新规则重新分析原始 STEP，并使旧 CAM 结果失效
- `PATCH /api/v1/jobs/{job_id}/features/{feature_id}`：确认或排除候选特征
- `PATCH /api/v1/jobs/{job_id}/safety`：更新安全间隙与夹持高度，并使旧批准失效
- `POST /api/v1/jobs/{job_id}/approve`：批准当前工艺草案
- `POST /api/v1/jobs/{job_id}/cam`：生成 FreeCAD Path 工程与 G-code
- `GET /api/v1/jobs/{job_id}/cam`：读取任务已经生成的 CAM、预检、仿真和碰撞结果
- `GET /api/v1/config`：读取前端使用的公开访问地址和会话分享能力
- `GET /api/v1/benchmarks/cases`：读取只读挂载的 2D/3D 回归案例清单
- `GET /api/v1/benchmarks/report`：读取最近一次真实案例覆盖率基线
- `GET /api/v1/jobs/{job_id}/files/{filename}`：下载结果文件

每个新工艺方案都包含 `coverage`，用于报告制造目标覆盖率、未识别内部轮廓、待复核特征、实验级工序和临时刀具。工作台顶部的“覆盖”按钮可打开详细问题列表。

使用仓库旁的 10 组 2D/3D 案例生成识别与规划基线：

```powershell
docker compose exec -T api python tools/evaluate_examples.py `
  --root /var/lib/seksun-cnc/examples `
  --output /var/lib/seksun-cnc/benchmark-report.json
```

报告会写入 `.seksun-cnc/benchmark-report.json`，原始案例目录以只读方式挂载，不会被修改，也不会调用 Qwen。

## 测试

```powershell
docker compose run --rm api /opt/venv/bin/python -m pytest -q -p no:cacheprovider
cd apps/web
npm run lint
npm run build
```

v0.8 验证结果：后端 27 项测试通过；前端 lint 和生产构建通过。真实 `sample-2.stp` 端到端测试生成 7 道工序、122 条 Path 指令和 24 条切削线段。真实 `0437S001ZU_20231121.stp` 的 `+X / +Y` 两次装夹生成 10/10 道工序、171 条 Path 指令和 3,891 字节 G-code，不再因缺少 `+Z` Setup 失败；每个 Setup 均使用独立安全平面与钳口禁入区。薄板样件 `f019a56005-01.stp` 正确恢复 5×Ø6.5 与 1×Ø7 通孔，并生成带半径补偿和四个桥位的外轮廓刀路；钻尖穿透和牺牲垫板校核通过，目标体积仿真偏差约 4.3%。

v0.4 的 10 个真实 STEP 批量结果保存在本地 `.seksun-cnc/batch-results-v04.json`（该目录默认不提交）：10 个样本均完成分析，面邻接约束把型腔候选从 149 个降至 62 个，减少约 58%。

## 当前边界

- 当前 CAM 支持将六个正交装夹方向转换为各自局部 `+Z`，生成面铣、钻孔/螺旋镗孔、矩形型腔/槽粗精加工和薄板外轮廓分层加工草案；多 Setup 之间仍需人工换装、找正并重设工件坐标。
- 刀具、转速、进给、切深、坐标系与后处理配置仍是候选值，需要结合真实机床和刀具库复核。
- 已实现 +Z 三轴平底刀近似材料去除，以及刀具/刀柄圆柱包络对毛坯和轴对齐夹具禁入盒的保守碰撞检查；尚未实现球刀/圆鼻刀精确轮廓、复杂夹具曲面、主轴头与机床运动学和 PMI/公差驱动规划。
- CAMotics 1.2 官方 Debian 二进制依赖已经淘汰的 `libv8.so.3.14.5`，不进入主镜像；后续将以隔离服务或维护中的仿真内核替代。
- 高度场结果是离散近似，会受网格精度影响，不能替代专业机床数字孪生验证。
- 薄板外轮廓桥位使用等距候选位置，尚未根据真实压板、真空吸盘或零件刚性自动优化；异形内部闭合轮廓仍会被能力检查拦截。
- 当前夹具由零件包围盒与夹持高度自动估算，实际钳口、软爪、压板和刀柄尺寸必须按现场配置校核。
- 输出不可未经工程师审核直接上机。G-code 下载按钮中的“草案”是刻意保留的安全边界。

依赖与许可证边界见 [OPEN_SOURCE.md](OPEN_SOURCE.md)。
